# 💸 Gestor de Gastos Personales

Aplicación web para la gestión de gastos personales que permite registrar, editar y visualizar gastos de forma sencilla, incluyendo un resumen visual mediante gráficos.

Proyecto desarrollado como práctica de JavaScript Vanilla, enfocado a simular un caso real de uso y orientado a portfolio.

---

## 🚀 Funcionalidades

- ➕ Añadir nuevos gastos
- ✏️ Editar gastos existentes
- 🗑 Eliminar gastos
- 🔍 Ver el detalle de cada gasto
- 📊 Visualizar una gráfica con los gastos
- 💾 Persistencia de datos usando LocalStorage
- 📱 Interfaz sencilla e intuitiva

---

## 🛠 Tecnologías utilizadas

- **HTML5** – estructura semántica de la aplicación  
- **CSS3** – diseño y maquetación (Flexbox / Grid)  
- **JavaScript (ES6+)** – lógica de la aplicación  
- **LocalStorage** – almacenamiento local de los gastos  

---

## 📊 Gráfica de gastos

La aplicación incluye una gráfica que permite visualizar de forma clara los gastos registrados, facilitando el análisis del consumo.
